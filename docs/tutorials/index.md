# Tutorials

The Quick Starts cover the basics: install Ambrosia, set it up, add a product and make your first sale. These tutorials go deeper into each part of Ambrosia, one topic per page.

They work the same no matter how you installed Ambrosia (Desktop App, Docker or Native). When a step is different for one install method, the page says so.
