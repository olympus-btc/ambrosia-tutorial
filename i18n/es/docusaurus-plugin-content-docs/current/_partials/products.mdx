# Gestión de Productos

## 1. Abre la Página de Productos
- Desde el Dashboard → **Productos**
- Verás la lista de productos existentes (nombre, precio, stock, acciones).

## 2. Agregar un Producto

### Paso 1 — Haz clic en "Agregar Producto"
Botón en la parte superior derecha.

### Paso 2 — Completa los campos

**Nombre del Producto** y **Precio** son obligatorios, y también el stock mientras **Controlar almacén** esté activado.

**Nombre del Producto**
```
5 Sticker Pack
```

**Descripción del Producto** (opcional)
```
Pack with 5 random stickers
```

**Categoría del Producto** (opcional): escribe un nombre y elige **+ Crear "Stickers"** para crear la categoría en el momento. Un producto puede tener más de una categoría.

```
Stickers
```

**SKU** (opcional)
```
PK-STICK-05
```

**Precio**: en la moneda de tu tienda.
```
1
```

**Stock**
```
20
```

Desactiva **Controlar almacén** para productos que no cuentas, como servicios.

**Imagen** (opcional): haz clic en **Sube una Imagen** y elige un PNG, JPG o GIF de hasta 5 MB (se recomienda formato cuadrado).

:::info
El formulario también tiene **Es un Paquete** y **Tiene variantes**, para productos formados por otros productos o que se venden en varias versiones, como tallas o colores. Las categorías también se administran desde la sección **Categorías**, debajo de la lista de productos. Consulta [Productos](../tutorials/products.md) para ver todo esto en detalle.
:::

### Paso 3 — Haz clic en "Agregar"
El producto aparece inmediatamente en la lista.

## 3. Editar un Producto

1. En la lista de productos, haz clic en **Editar** en el producto.
2. Cambia lo que necesites y haz clic en **Guardar**.

## 4. Eliminar un Producto

1. Haz clic en **Eliminar** en el producto.
2. Confirma con **Eliminar**. Esta acción no se puede deshacer.

Un producto que es componente de un paquete no se puede eliminar mientras forme parte de ese paquete.
