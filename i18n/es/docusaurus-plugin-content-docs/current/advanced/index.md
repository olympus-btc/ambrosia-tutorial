# Avanzado

Los Inicios Rápidos y los Tutoriales tratan sobre cómo usar Ambrosia en tu tienda. Estas guías son para quien instala y mantiene la computadora donde corre Ambrosia: despliegue, mantenimiento y solución de problemas.

Cada guía indica a qué métodos de instalación aplica.
