# Tutoriales

Los Inicios Rápidos cubren lo básico: instalar Ambrosia, configurarlo, agregar un producto y hacer tu primera venta. Estos tutoriales profundizan en cada parte de Ambrosia, un tema por página.

Funcionan igual sin importar cómo instalaste Ambrosia (App de Escritorio, Docker o Nativo). Cuando un paso cambia según el método de instalación, la página lo indica.
